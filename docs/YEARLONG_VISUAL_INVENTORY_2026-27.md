## Integration and release checklist
1. Keep draft PRs separate until reviewed. **Overlapping HTML files:** Math `math/index.html` in #6, #8 and #10; Science `science/index.html` in #4 and #9; ELA `ela/index.html` in #5. These require reconciliation and combined tests before merging. Do not assume independent green CI means the combined version works.
2. Integrate and test the shared quiz-handler fix in #2 before deploying other lesson tools. Current main binds generic `.opt` controls and can hijack tool buttons.
3. For each visual: verify actual Drive lesson and grade-level outcome; inspect mathematics and scientific assumptions; keyboard and screen-reader labels; narrow-phone and school laptop/touch use; empty, invalid and reset states; zero external trackers; no student data or teacher answer keys.
4. Keep the live site untouched until teacher approval. **LocalStorage is not an assessment/gradebook.** GitHub Actions green means static regression checks passed, not that the classroom experience is approved.
